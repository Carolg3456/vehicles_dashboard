# Vehicle Market Intelligence Dashboard (US)
Interactive Web App for Pricing & Inventory Insights

Aplicación web interactiva desarrollada con Streamlit, diseñada para analizar y visualizar información clave del mercado de vehículos en venta en EE. UU., orientada a apoyar decisiones comerciales, estrategias de pricing y análisis de inventario.

## 🎯 Valor para negocio

Permite identificar patrones de precios, antigüedad y uso de los vehículos, facilitando la detección de tendencias de mercado, oportunidades de optimización de precios y comportamientos relevantes para equipos comerciales y de negocio.

⚙️ Funcionalidades clave

Visualización de la distribución del kilometraje (odómetro) para evaluar el estado del inventario.

Análisis de la relación entre precio y año del modelo mediante gráficos de dispersión interactivos.

Controles y filtros dinámicos para exploración ágil de datos.

Interfaz intuitiva, accesible para usuarios no técnicos.
